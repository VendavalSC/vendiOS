vendiOS

Arch Linux with a desktop I wrote myself: the window manager, the bar, the lock screen and the installer. I use it every day on the laptop I build it on, and this is the first version I’m putting out for other people.

It’s for people coming from Mint or Ubuntu who want to try a tiling desktop without spending a weekend in config files. Everything on this page works on a fresh install. You don’t have to edit anything first.

What’s in it

vendiWM is the window manager, written in Rust on Smithay. Windows tile on their own, but you can still grab one with the mouse and drop it somewhere else, and the layout rearranges around it. It does tab groups, a scratchpad, pinned windows, more than one monitor, and XWayland for apps that still need X11. Animations run on springs.

Two bars come with it and you pick one in the installer. Pro is a notch at the top of the screen that opens up into media controls, weather and a dashboard. Classic is just text and icons. vendi bar switches between them later.

The disk is btrfs. A snapshot is taken before and after every package update, so if an update breaks something, vendi rollback puts you back where you were.

The vendi command handles most of what you’d otherwise go looking for a settings app to do: Wi‑Fi, Bluetooth, audio, themes, screenshots, updates. It’s listed further down.

On first login a short tour opens and walks you through the basic moves by having you actually do them. You can reopen it any time with vendi welcome.

Installing

  1. Write the ISO to a USB stick. On Linux: sudo dd if=vendios-2026.09.24-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync. On Windows or macOS, Fedora Media Writer or balenaEtcher will do it.
  2. Turn off Secure Boot in your firmware settings and boot from the stick.
  3. The installer starts on its own. It asks for language, timezone and keyboard; which disk to use (the whole disk, free space, or your own partitions); btrfs or ext4; whether to encrypt; your user and hostname; which bar; and optional extras like swap and the yay AUR helper.
  4. Nothing is written to the disk until the last screen, where you confirm.
  5. Reboot, log in, and you’re at the desktop.

Encryption is on by default: LUKS2 with argon2id. You type the passphrase once at boot.

To check the download: sha256sum -c vendios-2026.09.24-x86_64.iso.sha256, with the .sha256 file from the release page next to the ISO.

Building the ISO yourself

sudo pacman -S archiso limine xorriso
git clone https://github.com/VendavalSC/vendiOS
cd vendiOS
sudo ./build.sh --clean --offline   # ends up in out/

Leave out --offline for a much smaller ISO that downloads packages while it installs.

The vendi command

Run vendi on its own to see everything. These are the ones you’ll use most.

vendi updateRefresh mirrors and upgrade everything
vendi snapshotTake or manage btrfs snapshots
vendi rollbackGo back to an earlier snapshot
vendi cleanClear the package cache and trim the journal
vendi wifi · bt · audioNetworks, Bluetooth devices, speakers and mics
vendi displayArrange monitors: scale, position, resolution
vendi themeRecolour the whole desktop
vendi appearanceLight, dark, or whichever suits the wallpaper
vendi wallpaperSet a wallpaper, or a day/night pair
vendi barSwitch between the Pro and Classic bars
vendi shot · recordScreenshots and screen recordings
vendi ocrSelect part of the screen, copy the text in it
vendi clipClipboard history
vendi nightNight light
vendi powerPower profile
vendi fingerprintEnroll a finger to unlock the lock screen
vendi webappTurn a website into an app, e.g. vendi webapp add whatsapp
vendi devInstall a dev toolchain and a preconfigured Neovim
vendi gameInstall the gaming stack
vendi reportPack logs and system info into one file for a bug report

Themes and wallpapers

vendi theme recolours the bar, the terminal and GTK apps together, with no restart. It ships with mocha, latte, gruvbox, nord, tokyonight, everforest, mono and think. There’s also dynamic, which picks the colours from your wallpaper.

Wallpapers go in ~/Pictures/Wallpapers. Give vendi wallpaper dynamic set a day picture and a night picture (and a dusk one if you want), and it swaps between them over the day.

What isn’t done

It’s a beta, and mostly one person’s work. What I know about:

  • Secure Boot isn’t supported yet. It’s on the list.
  • Fractional scaling (125%, 150%) on high-DPI screens hasn’t had much testing.
  • The local AI assistant you’ll see in the code isn’t on this ISO yet.

So far it’s been tested on AMD and Intel CPUs, AMD and NVIDIA graphics, two monitors, and an Intel Chromebook. Keep a backup of anything you care about.

Questions

Can I install it next to Windows?
Yes. Pick “free space” or your own partitions in the installer instead of the whole disk.
Is it still Arch underneath?
Yes. pacman and the AUR work as normal, and updates come straight from Arch.
Something broke. What do I send you?
Run vendi report and attach the file it makes to an issue on GitHub. Say what you were doing when it happened.
