vendiOS

Minimal. Modern. Yours.

An Arch-based Linux distribution built from scratch around its own Wayland compositor, its own notch-style bar, and a TUI installer that gets out of your way. No Hyprland, no Waybar, no borrowed desktop — vendiOS is its own thing, end to end.

Install vendiOS Source on GitHub
● actively developed — daily-driven by its own maintainer

What's in the box

Everything below is native to vendiOS — built for it, not bolted on.

vendiWM

A Rust/Smithay Wayland compositor with direct-manipulation "liquid" tiling, spring-physics animations, touch gestures, and per-window blur/opacity.

vendiBar

Two flavors: a minimal classic GTK4 bar, or vendiBar Pro — a dynamic-island-style notch with media, weather, AI, and system cards.

TUI installer

Full-screen dialog-driven installer — disk layout, encryption, swap, desktop choice, all before a single package downloads.

Built-in local AI

vendi ai (super+space) is a fully local, system-aware assistant — no cloud, no API keys.

Live theming

Switch accent themes and light/dark mode without a restart; wallpapers can auto-rotate through sunrise/day/afternoon/night sets.

btrfs snapshots

Automatic snapper timeline + vendi snapshot / vendi rollback for one-command recovery.

Design

  • btrfs by default (ext4 also supported), zstd compression, subvolume layout for clean snapshots.
  • Limine bootloader — the same loader boots the live ISO and the installed system.
  • Optional full-disk encryption (LUKS2) with a pbkdf2 KDF, chosen specifically because it's what GRUB/Limine's pre-boot crypto can reliably unlock.
  • The vendi CLI is the one entry point for nearly everything — theming, capture, power, snapshots, dev tooling.

Installing vendiOS

Boot the ISO, run vendi-install, answer a handful of screens.

Build the ISO

sudo pacman -S archiso limine xorriso
sudo bash build.sh --clean

# ISO lands at out/vendios-YYYY.MM.DD-x86_64.iso

Write it to a USB stick with dd, or boot it directly in a VM.

The installer walkthrough

The live ISO boots straight to vendi-install, a full-screen TUI. It walks through, in order:

StepWhat you're choosing
Locale, timezone, keyboardStandard picks — searchable lists, not free typing.
Disk & partition modeWhole-disk or manual; filesystem: btrfs (default) or ext4.
EncryptionLUKS2 full-disk encryption, on by default — pbkdf2 KDF specifically so the bootloader can unlock it pre-boot.
UsersHostname, root password, your user account.
BarvendiBar (classic, minimal) or vendiBar Pro (notch/island style).
ExtrasAUR helper (yay), swap (none / zram / swapfile).
Confirm & installNothing touches the disk until this screen.
Why pbkdf2, not the LUKS2 default (Argon2id)? Argon2id is the safer default for a normal Linux boot, but a bootloader's pre-boot crypto implementation is much more constrained — it can fail to unlock an Argon2id header at all, which looks exactly like a wrong passphrase. vendiOS trades a bit of KDF strength for boot reliability.

After install

Reboot, log in, and you're on a working desktop already — no first-run setup wizard, no missing codecs.

The vendi CLI

One command, most of the OS. Run vendi with no arguments for the full built-in list.

System

vendi updateRefresh mirrors and run a full system upgrade.
vendi cleanClear the package cache and orphaned dependencies.
vendi snapshotTake a btrfs snapshot right now (on top of the automatic timeline).
vendi rollbackRoll the system back to a previous snapshot.
vendi powerView or switch the power profile (power-saver / balanced / performance).

vendi fingerprintEnroll or manage fingerprint auth.

vendiBar

Pick your style during install, or switch anytime with vendi bar classic|pro.

Classic

A minimal GTK4 bar. Text and icons over your wallpaper — no pills, no glow, macOS-style restraint.

Pro

A dynamic-island-style notch: media playback, weather, AI, Claude Code status, battery, and a full control center all live in one expanding island.

Both are driven by the same underlying state — switching bars doesn't lose your wallpaper, theme, or config.

Theming & wallpapers

Themes

vendi theme <name> switches instantly, no restart: mocha, latte, gruvbox, nord, tokyonight, everforest, mono, or dynamic (derives an accent from your current wallpaper).

Day/night wallpapers

Group a set of wallpapers (sunrise / day / afternoon / night variants) and vendiOS will rotate through them automatically on a schedule you set — vendi wallpaper dynamic. Appearance (light/dark) can follow the active wallpaper's own brightness automatically too.

FAQ

Is vendiOS ready to daily-drive?

It's actively developed and daily-driven by its own maintainer. Multi-monitor support is still catching up (a known gap), and it's a young project generally — go in with that expectation.

Can I install without wiping the whole disk?

The installer supports manual partitioning alongside its whole-disk mode.

What if the LUKS passphrase seems to fail on first boot?

Make sure you're on a build with the pbkdf2 fix (see the callout in Installing) — that specific failure mode is what it addresses.

Where do I report bugs or follow development?
